Variables, funciones y decisiones

Objetivo: Distinguir valores, funciones y condiciones en un programa sencillo.

Una variable guarda un valor. const impide reasignar la referencia; let permite reasignarla. Una función agrupa instrucciones y puede devolver un resultado. Una condición selecciona qué bloque ejecutar.

Ejemplo: const precio = 10; const cantidad = 3; function total(p, c) { return p * c; }. total(precio, cantidad) devuelve 30. Una condición if (cantidad > 0) permite validar antes de calcular.

Actividad: Escribe una función que reciba dos precios y devuelva su suma. Después añade una condición que rechace precios negativos.

Arreglos y transformación de datos

Objetivo: Elegir map o filter para transformar una lista sin modificarla directamente.

Un arreglo agrupa valores ordenados. map crea un arreglo con el resultado de aplicar una función a cada elemento. filter crea un arreglo con los elementos que cumplen una condición. Ninguno modifica el arreglo original por sí mismo.

Ejemplo: [2, 4, 6].map(n => n * 2) produce [4, 8, 12]. [2, 4, 6].filter(n => n > 3) produce [4, 6]. map transforma; filter selecciona.

Actividad: A partir de una lista de tres productos, filtra los que tienen stock y transforma sus nombres a mayúsculas.
